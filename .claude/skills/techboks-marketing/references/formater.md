# Skabeloner

Udfyld — lever aldrig skabelonen med pladsholdere i.

---

## Instagram-opslag

```
[HOOK — én linje, problemet, ikke produktet]

[2–4 linjer: hvordan det er løst. Konkret. Mål, materiale, montering.]

[Én linje om at det er tegnet fra bunden / målt op i bilen]

[Pris] kr. — link i bio · techboks.dk/produkter/<slug>

#hashtag #hashtag …
```

Hooks der virker: *"Ford glemte …"* · *"Det her hul har irriteret mig i to år."* · *"Elbilen er lydløs — indtil …"* · *"Jeg målte det op og tegnede det selv."*

## Reel-manus

```
LÆNGDE: 15–25 sek.

0–3 sek.  HOOK (vis problemet)
          Billede: …
          Tekst på skærm: "…"
3–8 sek.  KONTEKST / hvordan det er lavet
          Billede: …
8–18 sek. MONTERING eller EFFEKT
          Billede: …
18–22 sek. RESULTAT + pris
          Tekst på skærm: "… kr · techboks.dk"

Undertekster: ja, altid
Lyd: [trend / stille med voiceover]
Caption: [2 linjer + hashtags]
```

## Facebook-gruppeopslag

```
[Åbning som ejer, ikke som butik — dit eget problem]

[Hvad du gjorde ved det. Proces: målt op, tegnet, printet, testet.]

[Konkret detalje der beviser præcisionen]

[Blødt tilbud: "Jeg printer dem også til andre — sig til hvis nogen er interesserede"
 ELLER pris + link, hvis gruppens regler tillader salg]

3–4 billeder: [hvilke]
```

Tjek gruppens salgsregler før hvert opslag.

## Produkttekst til webshoppen

Skal kunne indsættes direkte i `src/data/products.ts`:

```
shortDescription: [maks ~55 tegn, konkret nytte, ingen punktum til sidst]

description: [2–3 sætninger. Problem → løsning → én detalje der beviser
pasformen. Ingen superlativer. Ingen "vi".]

specifications:
  Materiale: PETG (…)
  Anvendelse/Montering: …
  Farver: Vælg selv farve af logo
  [evt. Kapacitet / Kompatibilitet / Bæreevne]
```

## SEO-meta

```
title:       <Produktnavn> til Mustang Mach-E — TechBoks     (maks ~60 tegn)
description: <Problem + løsning + dansk produktion + pris>     (maks ~155 tegn)
og:title:    <som title>
og:description: <kortere, mere sælgende variant>
```

---

## Annonce (Meta)

```
Primær tekst (125 tegn synligt før "se mere"):
  [Hook + løfte]
Overskrift (40 tegn):
  [Produkt + nytte]
Beskrivelse (30 tegn):
  [Pris eller dansk produktion]
CTA-knap: Køb nu / Læs mere
Landingsside: techboks.dk/produkter/<slug>
Kreativ: [beskrivelse]
Variant B: [anden vinkel, samme produkt]
```

## Nyt produkt — lanceringspakke

Lever altid alle fem dele samlet:
1. Produkttekst til shoppen (formatet ovenfor)
2. SEO-meta
3. Instagram-opslag
4. Reel-manus
5. Gruppeopslag til ejergrupperne

Plus: liste over de fotos/klip der skal optages, før noget af det kan udgives.
